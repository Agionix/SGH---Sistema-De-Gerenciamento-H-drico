Firmwares Oficiais C++ Sem Margem de Erro

Estes códigos foram desenvolvidos com leitura atômica de interrupções (noInterrupts() / interrupts()), strings em memória Flash (F() para evitar estouro de SRAM no ATmega328P), rotinas ISR em IRAM_ATTR para o ESP32 e cálculo com delta de tempo exato. Copie e cole diretamente na Arduino IDE sem necessidade de bibliotecas externas complexas.

Arduino Uno / Nano / Mega / Pro Mini (Pino Digital 2 / 115200 bps) 
/*
  =============================================================================
  SGH — SISTEMA DE GERENCIAMENTO HIDRÁULICO
  FIRMWARE OFICIAL ZERO-ERRO PARA ARDUINO (UNO / NANO / MEGA / PRO MINI)
  =============================================================================
  Sensor de Fluxo: YF-S201 (Efeito Hall)
  Pino de Sinal:   Pino Digital 2 (Interrupção INT0)
  Baud Rate:       115200 bps
  
  MÉTODO DE SEGURANÇA:
  - Cópia atômica via noInterrupts()/interrupts() (sem perda de pulsos)
  - Flash Strings F() para ZERO fragmentação da memória SRAM (2KB)
  - Cálculo temporal deltaSeconds exato (imune a pequenas variações de loop)
  =============================================================================
*/

const byte SENSOR_PIN = 2;
const float CALIBRATION_FACTOR = 7.5; // YF-S201: Freq(Hz) = 7.5 * Q(L/min)

volatile unsigned long pulseCounter = 0;
float flowRateLmin = 0.0;
float totalLiters = 0.0;
unsigned long previousMillis = 0;

void isrPulse() {
  pulseCounter++;
}

void setup() {
  Serial.begin(115200);
  while (!Serial) { ; }

  pinMode(SENSOR_PIN, INPUT_PULLUP);
  attachInterrupt(digitalPinToInterrupt(SENSOR_PIN), isrPulse, FALLING);
  previousMillis = millis();

  Serial.println(F("[SGH] Arduino iniciado com sucesso a 115200 bps."));
}

void loop() {
  unsigned long currentMillis = millis();

  if ((currentMillis - previousMillis) >= 1000) {
    // Leitura atômica protegida
    noInterrupts();
    unsigned long pulses = pulseCounter;
    pulseCounter = 0;
    interrupts();

    float deltaSeconds = (currentMillis - previousMillis) / 1000.0;
    previousMillis = currentMillis;

    // Cálculo exato da vazão instantânea e volume acumulado
    flowRateLmin = (pulses / deltaSeconds) / CALIBRATION_FACTOR;
    totalLiters += (flowRateLmin / 60.0) * deltaSeconds;

    // Envio direto do payload JSON reconhecido nativamente pelo SGH
    Serial.print(F("{\"vazao_lmin\":"));
    Serial.print(flowRateLmin, 2);
    Serial.print(F(",\"litros_totais\":"));
    Serial.print(totalLiters, 2);
    Serial.print(F(",\"status\":\"normal\",\"dispositivo\":\"arduino\"}\r\n"));
  }
}
ESP32 DevKit / NodeMCU-32S (USB Serial / GPIO 4 / 115200 bps) 
/*
  =============================================================================
  SGH — SISTEMA DE GERENCIAMENTO HIDRÁULICO
  FIRMWARE OFICIAL ZERO-ERRO PARA ESP32 (USB SERIAL)
  =============================================================================
  Sensor de Fluxo: YF-S201 (Efeito Hall)
  Pino de Sinal:   GPIO 4 (Recomendado) ou GPIO 2
  Baud Rate:       115200 bps
  
  MÉTODO DE SEGURANÇA:
  - ISR alocada em memória rápida IRAM (IRAM_ATTR) sem quedas por cache flash
  - PortMUX critical section atômica para integridade absoluta dos pulsos
  - Saída JSON validada para o conector USB e Web Serial do SGH
  =============================================================================
*/

#include <Arduino.h>

const int SENSOR_PIN = 4;
const float CALIBRATION_FACTOR = 7.5;

volatile uint32_t pulseCount = 0;
portMUX_TYPE synchMux = portMUX_INITIALIZER_UNLOCKED;

float flowRateLmin = 0.0;
float totalLiters = 0.0;
unsigned long lastCalcTime = 0;

void IRAM_ATTR isrFlowPulse() {
  portENTER_CRITICAL_ISR(&synchMux);
  pulseCount++;
  portEXIT_CRITICAL_ISR(&synchMux);
}

void setup() {
  Serial.begin(115200);
  delay(150);

  pinMode(SENSOR_PIN, INPUT_PULLUP);
  attachInterrupt(digitalPinToInterrupt(SENSOR_PIN), isrFlowPulse, FALLING);
  lastCalcTime = millis();

  Serial.println(F("\n[SGH] ESP32 Serial Inicializado. Conecte ao SGH a 115200 bps."));
}

void loop() {
  unsigned long now = millis();

  if ((now - lastCalcTime) >= 1000) {
    portENTER_CRITICAL(&synchMux);
    uint32_t pulses = pulseCount;
    pulseCount = 0;
    portEXIT_CRITICAL(&synchMux);

    float deltaSec = (now - lastCalcTime) / 1000.0;
    lastCalcTime = now;

    flowRateLmin = (pulses / deltaSec) / CALIBRATION_FACTOR;
    totalLiters += (flowRateLmin / 60.0) * deltaSec;

    Serial.printf("{\"vazao_lmin\":%.2f,\"litros_totais\":%.2f,\"status\":\"normal\",\"dispositivo\":\"esp32\"}\r\n", 
                  flowRateLmin, totalLiters);
  }
}
ESP32 Wi-Fi HTTP Direto (Sem Cabo USB / Auto-Reconexão) 
/*
  =============================================================================
  SGH — SISTEMA DE GERENCIAMENTO HIDRÁULICO
  FIRMWARE ZERO-ERRO PARA ESP32 (WI-FI HTTP POST DIRETO)
  =============================================================================
  Envia dados a cada segundo diretamente para o servidor SGH pela rede Wi-Fi.
  Totalmente imune a bloqueios de portas COM do Windows!
  Possui auto-reconexão inteligente se o roteador reiniciar.
  =============================================================================
*/

#include <WiFi.h>
#include <HTTPClient.h>

// --- CONFIGURAÇÃO DA REDE WI-FI ---
const char* WIFI_SSID = "NOME_DO_SEU_WIFI";
const char* WIFI_PASS = "SENHA_DO_SEU_WIFI";

// URL do Servidor SGH (Ajuste para o IP ou domínio da sua aplicação)
const char* SGH_ENDPOINT = "https://ais-dev-nq2ppqizafkhllgb42fqd7-516525678877.us-west1.run.app/api/telemetria/leitura";

const int SENSOR_PIN = 4;
const float CALIBRATION_FACTOR = 7.5;

volatile uint32_t pulseCount = 0;
portMUX_TYPE synchMux = portMUX_INITIALIZER_UNLOCKED;

float flowRateLmin = 0.0;
float totalLiters = 0.0;
unsigned long lastCalcTime = 0;

void IRAM_ATTR isrFlowPulse() {
  portENTER_CRITICAL_ISR(&synchMux);
  pulseCount++;
  portEXIT_CRITICAL_ISR(&synchMux);
}

void connectWifi() {
  if (WiFi.status() == WL_CONNECTED) return;
  Serial.print("[SGH] Conectando ao Wi-Fi: ");
  Serial.println(WIFI_SSID);
  WiFi.mode(WIFI_STA);
  WiFi.begin(WIFI_SSID, WIFI_PASS);
  
  int attempts = 0;
  while (WiFi.status() != WL_CONNECTED && attempts < 20) {
    delay(500);
    Serial.print(".");
    attempts++;
  }
  if (WiFi.status() == WL_CONNECTED) {
    Serial.println("\n[SGH] Wi-Fi Conectado! IP: " + WiFi.localIP().toString());
  } else {
    Serial.println("\n[SGH] Falha ao conectar. Nova tentativa no proximo ciclo.");
  }
}

void setup() {
  Serial.begin(115200);
  pinMode(SENSOR_PIN, INPUT_PULLUP);
  attachInterrupt(digitalPinToInterrupt(SENSOR_PIN), isrFlowPulse, FALLING);
  connectWifi();
  lastCalcTime = millis();
}

void loop() {
  unsigned long now = millis();

  if ((now - lastCalcTime) >= 1000) {
    portENTER_CRITICAL(&synchMux);
    uint32_t pulses = pulseCount;
    pulseCount = 0;
    portEXIT_CRITICAL(&synchMux);

    float deltaSec = (now - lastCalcTime) / 1000.0;
    lastCalcTime = now;

    flowRateLmin = (pulses / deltaSec) / CALIBRATION_FACTOR;
    totalLiters += (flowRateLmin / 60.0) * deltaSec;

    Serial.printf("[LOCAL] Vazao: %.2f L/min | Total: %.2f L\n", flowRateLmin, totalLiters);

    if (WiFi.status() == WL_CONNECTED) {
      HTTPClient http;
      http.begin(SGH_ENDPOINT);
      http.addHeader("Content-Type", "application/json");

      char payload[160];
      snprintf(payload, sizeof(payload),
               "{\"vazao_lmin\":%.2f,\"litros_totais\":%.2f,\"status\":\"normal\",\"dispositivo\":\"esp32\"}",
               flowRateLmin, totalLiters);

      int httpCode = http.POST(payload);
      if (httpCode > 0) {
        Serial.printf("[HTTP] Sucesso -> Codigo: %d\n", httpCode);
      } else {
        Serial.printf("[HTTP] Falha de envio: %s\n", http.errorToString(httpCode).c_str());
      }
      http.end();
    } else {
      connectWifi();
    }
  }
}

Central de Dúvidas & Guia Completo de Instalação do Microcontrolador

ESP32 (DevKit v1 / NodeMCU-32S): Lógica 3.3V / 5V Tolerante
VCC (Fio Vermelho) → Conectar ao pino VIN (5V)
GND (Fio Preto) → Conectar a qualquer pino GND
SINAL (Fio Amarelo) → Conectar ao GPIO 4 (Recomendado) ou GPIO 2

O GPIO 4 não interfere com os pinos de strapping durante o boot do ESP32.

Arduino (Uno / Nano / Mega / Pro Mini): Lógica 5V Nativa
VCC (Fio Vermelho) → Conectar ao pino 5V
GND (Fio Preto) → Conectar a qualquer pino GND
SINAL (Fio Amarelo) → Conectar ao Pino Digital 2 (INT0)

O Pino 2 possui interrupção por hardware dedicada (INT0) no chip ATmega328P.

1. Por que o site não conecta quando a janela da Arduino IDE está aberta?

Tanto o Windows quanto o Linux e o macOS possuem uma regra de exclusividade para periféricos seriais USB: apenas um aplicativo pode abrir uma porta COM por vez. Se a janela do Serial Monitor da Arduino IDE estiver aberta exibindo linhas de dados, a porta COM3 fica travada e o navegador receberá erro de acesso negado pelo sistema operacional.

Como resolver: Feche a janelinha do Monitor Serial na Arduino IDE antes de clicar no botão "Conectar via Cabo USB" no navegador.

2. Como posicionar o sensor YF-S201 na tubulação de água?

O sensor de fluxo YF-S201 possui uma seta em alto-relevo gravada na lateral da carcaça preta. Essa seta indica a direção obrigatória em que a água deve passar.

Se você instalar o sensor ao contrário, a água girará a turbina magnética com turbulência inadequada, resultando em 0 pulsos por segundo ou leituras erráticas. Além disso, mantenha pelo menos 15 cm de tubo reto antes da entrada do sensor para evitar vórtices de curvas.

3. Preciso colocar resistor de pull-up externo na bancada?

Não para a bancada e conexões curtas! O sensor YF-S201 possui saída de transistor em coletor aberto (Open Collector). O nosso código ativa diretamente o resistor de elevação interno do microcontrolador com o comando pinMode(SENSOR_PIN, INPUT_PULLUP).

Um resistor físico externo (de 4.7kΩ ou 10kΩ entre o pino de Sinal e os 5V/3.3V) só é indispensável caso você passe fios longos (mais de 3 metros) em eletrodutos junto com fiação elétrica, para blindar contra ruídos induzidos.

4. O computador não reconhece a placa USB ou diz "Dispositivo Desconhecido"?

Placas clone ou de baixo custo utilizam circuitos integrados conversores USB-Serial como o CH340 ou Silicon Labs CP2102:

• Placas com CH340: Baixe o driver "WCH CH340/CH341 USB Driver" para Windows.
• Placas com CP2102 / CP2104: Baixe o driver "Silicon Labs CP210x VCP".
• Atenção ao cabo USB: Muitos cabos de recarga de celular não possuem as vias de dados internas (D+ e D-). Use um cabo USB com transmissão de dados testada.

5. Quais parâmetros selecionar na Arduino IDE para gravar o código?

• Arduino Uno: Menu Ferramentas → Placa → Arduino AVR Boards → Arduino Uno. Porta: selecione a porta COM correspondente.
• ESP32: Menu Ferramentas → Placa → esp32 → ESP32 Dev Module (ou NodeMCU-32S). Upload Speed: 921600 ou 115200.
• Taxa Baud Serial: O firmware transmite em 115200 bps. Mantenha essa velocidade configurada tanto no código quanto no navegador.

6. Por que na Vercel a auto-detecção não detecta o cabo USB no meu notebook?

Quando o site está hospedado na Vercel ou em servidores em nuvem, a auto-detecção do servidor procura portas USB físicas nos servidores remotos da AWS/Vercel, onde não há nenhum cabo conectado.

Para ler os dados da porta USB do seu notebook na Vercel:
• Opção 1 (Recomendada): Clique no botão azul "Conectar via Cabo USB (Web Serial)" no topo desta página. O navegador Google Chrome ou Microsoft Edge lê a porta USB do seu notebook e transmite os dados direto para o painel em tempo real!
• Opção 2 (ESP32 Wi-Fi): Grave o código Wi-Fi oficial no ESP32. Ele enviará os dados diretamente pela rede sem precisar de cabo USB conectado ao computador.
