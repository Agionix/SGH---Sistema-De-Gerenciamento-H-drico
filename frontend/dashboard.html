Código-Fonte & Esquema de Ligação

Esquema de Ligação — Arduino Uno / Nano / Mega / Pro Mini

VCC (Fio Vermelho) → Conectar ao pino 5V do Arduino
GND (Fio Preto) → Conectar ao pino GND do Arduino
SINAL (Fio Amarelo) → Conectar ao Pino Digital 2 (Interrupção de hardware INT0)

O código já habilita o resistor interno de pull-up com pinMode(2, INPUT_PULLUP), eliminando ruídos no sinal Hall.

Código C++ Zero-Erro para Arduino IDE:

/*
  =============================================================================
  SGH — SISTEMA DE GERENCIAMENTO HIDRÁULICO
  FIRMWARE OFICIAL ZERO-ERRO PARA ARDUINO (UNO / NANO / MEGA / PRO MINI)
  =============================================================================
  Sensor de Fluxo: YF-S201 (Efeito Hall)
  Pino de Sinal:   Pino Digital 2 (Interrupção INT0)
  Baud Rate:       115200 bps
  
  MÉTODO DE SEGURANÇA:
  - Cópia atômica via noInterrupts()/interrupts() (sem perda de pulsos)
  - Flash Strings F() para ZERO fragmentação da memória SRAM (2KB)
  - Cálculo temporal deltaSeconds exato (imune a pequenas variações de loop)
  =============================================================================
*/

const byte SENSOR_PIN = 2;
const float CALIBRATION_FACTOR = 7.5; // YF-S201: Freq(Hz) = 7.5 * Q(L/min)

volatile unsigned long pulseCounter = 0;
float flowRateLmin = 0.0;
float totalLiters = 0.0;
unsigned long previousMillis = 0;

void isrPulse() {
  pulseCounter++;
}

void setup() {
  Serial.begin(115200);
  while (!Serial) { ; }

  pinMode(SENSOR_PIN, INPUT_PULLUP);
  attachInterrupt(digitalPinToInterrupt(SENSOR_PIN), isrPulse, FALLING);
  previousMillis = millis();

  Serial.println(F("[SGH] Arduino iniciado com sucesso a 115200 bps."));
}

void loop() {
  unsigned long currentMillis = millis();

  if ((currentMillis - previousMillis) >= 1000) {
    // Leitura atômica protegida
    noInterrupts();
    unsigned long pulses = pulseCounter;
    pulseCounter = 0;
    interrupts();

    float deltaSeconds = (currentMillis - previousMillis) / 1000.0;
    previousMillis = currentMillis;

    // Cálculo exato da vazão instantânea e volume acumulado
    flowRateLmin = (pulses / deltaSeconds) / CALIBRATION_FACTOR;
    totalLiters += (flowRateLmin / 60.0) * deltaSeconds;

    // Envio direto do payload JSON reconhecido nativamente pelo SGH
    Serial.print(F("{\"vazao_lmin\":"));
    Serial.print(flowRateLmin, 2);
    Serial.print(F(",\"litros_totais\":"));
    Serial.print(totalLiters, 2);
    Serial.print(F(",\"status\":\"normal\",\"dispositivo\":\"arduino\"}\r\n"));
  }
}

Esquema de Ligação — ESP32 (DevKit v1 / NodeMCU-32S / ESP32-WROOM)

VCC (Fio Vermelho) → Conectar ao pino VIN (5V) do ESP32
GND (Fio Preto) → Conectar ao pino GND do ESP32
SINAL (Fio Amarelo) → Conectar ao GPIO 4 (ou GPIO 2)

O pino GPIO 4 é o recomendado para o ESP32 pois não interfere com o LED de boot nem com portas de strapping.

Código C++ Zero-Erro para ESP32 (USB Serial):

/*
  =============================================================================
  SGH — SISTEMA DE GERENCIAMENTO HIDRÁULICO
  FIRMWARE OFICIAL ZERO-ERRO PARA ESP32 (USB SERIAL)
  =============================================================================
  Sensor de Fluxo: YF-S201 (Efeito Hall)
  Pino de Sinal:   GPIO 4 (Recomendado) ou GPIO 2
  Baud Rate:       115200 bps
  
  MÉTODO DE SEGURANÇA:
  - ISR alocada em memória rápida IRAM (IRAM_ATTR) sem quedas por cache flash
  - PortMUX critical section atômica para integridade absoluta dos pulsos
  - Saída JSON validada para o conector USB e Web Serial do SGH
  =============================================================================
*/

#include <Arduino.h>

const int SENSOR_PIN = 4;
const float CALIBRATION_FACTOR = 7.5;

volatile uint32_t pulseCount = 0;
portMUX_TYPE synchMux = portMUX_INITIALIZER_UNLOCKED;

float flowRateLmin = 0.0;
float totalLiters = 0.0;
unsigned long lastCalcTime = 0;

void IRAM_ATTR isrFlowPulse() {
  portENTER_CRITICAL_ISR(&synchMux);
  pulseCount++;
  portEXIT_CRITICAL_ISR(&synchMux);
}

void setup() {
  Serial.begin(115200);
  delay(150);

  pinMode(SENSOR_PIN, INPUT_PULLUP);
  attachInterrupt(digitalPinToInterrupt(SENSOR_PIN), isrFlowPulse, FALLING);
  lastCalcTime = millis();

  Serial.println(F("\n[SGH] ESP32 Serial Inicializado. Conecte ao SGH a 115200 bps."));
}

void loop() {
  unsigned long now = millis();

  if ((now - lastCalcTime) >= 1000) {
    portENTER_CRITICAL(&synchMux);
    uint32_t pulses = pulseCount;
    pulseCount = 0;
    portEXIT_CRITICAL(&synchMux);

    float deltaSec = (now - lastCalcTime) / 1000.0;
    lastCalcTime = now;

    flowRateLmin = (pulses / deltaSec) / CALIBRATION_FACTOR;
    totalLiters += (flowRateLmin / 60.0) * deltaSec;

    Serial.printf("{\"vazao_lmin\":%.2f,\"litros_totais\":%.2f,\"status\":\"normal\",\"dispositivo\":\"esp32\"}\r\n", 
                  flowRateLmin, totalLiters);
  }
}

Guia de Instalação & Resolução de Dúvidas Técnicas

1. Por que o site não conecta se o Monitor Serial da Arduino IDE estiver aberto?

Os sistemas operacionais (Windows, Linux e macOS) concedem posse exclusiva à porta USB (COM3, /dev/ttyUSB0). Se a janela do Serial Monitor da Arduino IDE estiver aberta lendo os dados, o navegador será impedido pelo SO de abrir a porta. Solução: Feche a janela do Monitor Serial na Arduino IDE antes de clicar no botão Conectar.

2. Como posicionar o sensor de fluxo YF-S201 no encanamento?

O corpo plástico preto do sensor YF-S201 possui uma seta em alto-relevo indicando a direção correta do fluxo de água. A água DEVE entrar pelo lado indicado e sair pelo outro. Se for montado ao contrário, a turbina magnética interna gerará turbulência irregular e o sensor medirá 0 L/min.

3. É necessário colocar resistor de pull-up externo na bancada?

Não para a maioria das instalações! Nossos códigos oficiais configuram o pino de leitura com pinMode(SENSOR_PIN, INPUT_PULLUP), ativando o resistor interno de pull-up do Arduino e do ESP32. Só é recomendado um resistor físico externo de 4.7kΩ a 10kΩ caso o fio entre o sensor e a placa tenha mais de 3 metros de distância.

4. O computador não reconhece a placa USB ou dá "Dispositivo Desconhecido"?

A maioria das placas Arduino e ESP32 utiliza conversores USB-Serial como o CH340 ou Silicon Labs CP2102. Se a porta COM não aparecer no Gerenciador de Dispositivos do Windows, instale o driver oficial do chip da sua placa. Verifique também se o cabo USB utilizado suporta transferência de dados (cabos baratos que só carregam celular não possuem linhas de dados D+/D-).

5. Qual placa e velocidade configurar na Arduino IDE?
  • Arduino Uno: Ferramentas → Placa: "Arduino Uno" • Programador: "AVRISP mkII".
  • ESP32: Ferramentas → Placa: "ESP32 Dev Module" • Upload Speed: 921600 • Flash Frequency: 80MHz.
  • Taxa Baud: Sempre compile e grave com 115200 bps para compatibilidade direta com o SGH.
